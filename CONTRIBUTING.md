# Contributing to Human Signal Amplifier

This skill gets better every time it's used — and every
time someone notices where it could be sharper, more
specific, or more useful.

---

## Current contribution priorities

### 1. Intake question refinements

The 8 intake questions are the most important part of the
skill. If you use the skill and find that a question produces
vague answers, doesn't surface the signal it's designed for,
or could be asked more precisely — open an issue.

Include:
- The question as it currently reads
- What made it unclear or ineffective
- A proposed alternative wording

### 2. New signal dimension candidates

The five current dimensions — contextual judgment, relational
trust, reasoning under ambiguity, pattern recognition from
lived experience, and human presence — are a starting point.
If you have evidence of a sixth dimension that isn't captured
by any of the five, open an issue describing it.

Include:
- What the dimension is and what makes it distinct
- Which intake question(s) would surface it
- A real example of someone whose primary signal lives here

### 3. Output template improvements

The output template is designed to produce language people
can actually use. If you receive output that feels generic,
unclear, or not specific enough — open an issue with the
before and after.

The most useful contributions here: real examples of
output that landed well, and real examples of output
that missed.

### 4. Log entry patterns

The living system is the most experimental part of this
skill. If you use the experience logging feature and
notice patterns in what makes a log entry useful vs.
not — especially around what information is needed
to update a profile meaningfully — open an issue or PR.

### 5. Post lead formats

The post lead section currently offers four format options.
If you find a format that works better for a specific
audience or context — especially formats that have
actually been posted and received well — open a PR
adding it to the template.

---

## What this skill is not looking for

- Generic career advice that could go in any positioning tool
- Anything that locates the signal in credentials,
  titles, or formal qualifications
- Output templates that produce language nobody would
  actually say out loud
- Intake questions that make people feel assessed
  rather than understood

---

## How to contribute

1. Open an issue before significant changes — alignment
   first saves everyone time
2. Fork the repo and create a branch
3. Make your changes to the relevant file in
   `human-signal-amplifier/`
4. Submit a pull request with a clear description of
   what changed and why
5. Validate before submitting:
   `npx skills-ref validate ./human-signal-amplifier`

---

## Philosophy

This skill is built on one belief: the question "what do
I bring that AI can't?" is not a threat to navigate — it
is the most important positioning question of this decade.

Contributions should make it easier for more people to
answer that question specifically and honestly. A
contribution that helps one person find language that
is true to their actual experience is worth more than
a technically impressive feature nobody uses.
